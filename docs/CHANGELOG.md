# 変更履歴

## [1.0.10] - 2026-07-21

### 改善

- ボタンの標準設定と個別設定の適用範囲を分かりやすく表示

### 修正

- Electron上でスナップアイコンが中央からずれて見える問題を修正

## [1.0.9] - 2026-07-21

### 追加

- バージョン付きv2レイアウトJSON形式
- レイアウトJSONと参照画像をまとめる`.myogi`形式
- `.myogi`のインポート前確認と同名時の保存名表示

### 改善

- レイアウトパッケージを検証後に原子的にインポート
- ZIP容量、展開容量、ファイル数、画像署名を検証
- インポートの二重送信と未保存変更の破棄を防止
- 長いレイアウト名と背景画像名の表示を調整
- プレビュールーラー左上の重なりを解消
- 画像1枚の上限を15MBへ変更

### 修正

- Electron、エディターUI、コンポーネントテストの安定性を改善

## [1.0.0] - 2026-07-07

### 追加

- Myogi Ban初期リリース
- Electronアプリ起動
- Webサーバー単体起動
- OBSブラウザソース用ビューア
- React + TypeScriptの編集画面
- MantineベースのフォームUI
- i18next/react-i18nextによる日本語/英語切り替え
- Web Gamepad APIによるリアルタイム入力表示
- レバー/ボタンのCSS描画
- 背景、レバー、ボタン画像のアップロード
- ボタンとレバー方向のゲームパッド割り当て
- アナログ軸ホールドによる割り当て
- レイアウトの保存、読み込み、デフォルト指定
- レイアウトJSONのインポート/エクスポート
- REST APIとWebSocketによる状態配信
- electron-builderによる配布ビルド設定
