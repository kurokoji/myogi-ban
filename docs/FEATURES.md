# 機能一覧

## 入力表示

- レバーの上下左右と斜め入力を表示
- ボタン押下状態をリアルタイム表示
- Web Gamepad API対応デバイスを自動検出
- ゲームパッド接続/切断状態を編集画面に表示

## OBSビューア

- `/view` でOBSブラウザソース向けの軽量ビューアを提供
- 透過背景でゲーム画面へ重ねやすい構成
- デフォルトに設定したレイアウトをビューア起動時に読み込み
- 編集画面上部にOBS用URLを表示し、クリップボードへコピー可能

## レイアウト編集

- プレビュー上でボタンとレバーをドラッグして位置調整
- ボタン表示数を0から48まで設定
- ボタンごとに通常時/押下時のサイズ、画像、CSS色を設定
- 全ボタン共通の標準設定と、個別ボタン設定を併用
- レバーの表示/非表示、位置、拡大率を設定
- 背景の表示/非表示、透明度、サイズを設定
- 編集画面のプレビュー倍率を0.1から3.0まで調整

## CSS描画

- 画像を使わずに背景、ボタン、レバーをCSSで描画
- 背景色と角丸を設定
- ボタンの通常色/押下色、transition、easingを設定
- レバーのディスク色とレバーボール色を設定

## 画像利用

- 背景画像、標準ボタン画像、個別ボタン画像をアップロード
- 通常時画像と押下時画像を別々に指定
- 背景画像の倍率からOBS向け幅/高さを算出
- レイアウト保存時に参照中の画像アセットをユーザーレイアウトへコピー

## ボタン/レバー割り当て

- プレビュー上のボタンをクリックしてゲームパッドボタンを割り当て
- レバー方向をクリックして上下左右の入力を割り当て
- ゲームパッドのボタン入力に対応
- アナログ軸を1秒ホールドして軸入力として割り当て

## レイアウト管理

- 組み込みレイアウトとユーザーレイアウトの一覧表示
- レイアウトの読み込み、名前付き保存
- デフォルトレイアウト指定
- レイアウトJSONのエクスポート
- レイアウトJSONのインポート

## 多言語UI

- 日本語/英語を編集画面から切り替え
- 選択言語を `localStorage` に保存

## 起動形態

- `npm start`: Electronアプリとして起動
- `npm run start:web`: ローカルWebサーバーとして起動
- `npm stop`: Webサーバー単体起動時のPIDファイルを使って停止
- `npm run build:dist`: electron-builderで配布用パッケージを作成

## 制限事項

- サーバーのポートは `33770` 固定
- ボタン表示数のUI上限は48
- Gamepad APIの認識には、ブラウザ上でゲームパッドのボタン入力が必要な場合があります
- 画像アップロードAPIのJSON上限は100MB
- レイアウト共有時、画像ファイルはレイアウトJSONとは別に扱われます
