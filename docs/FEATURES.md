# 機能一覧

## 基本機能

### スティック表示

- **8方向対応**: 上、下、左、右、斜め4方向
- **視覚的フィードバック**: 入力方向に応じてスティックが回転
- **カスタマイズ可能**: 位置、サイズ、画像を変更可能

### ボタン表示

- **最大48ボタン**: 必要な数だけ表示
- **個別設定**: 各ボタンの位置、サイズ、画像を個別に設定
- **押下状態**: 押されているボタンが視覚的に変化

### 入力履歴

- **垂直表示**: 上から下へ履歴を表示
- **水平表示**: 左から右へ履歴を表示（上下2パターン）
- **表示数設定**: 1〜50件まで設定可能
- **同時押しモード**: 複数ボタン向けのボタン組み合わせ表示

## カスタマイズ機能

### 背景設定

- **背景画像**: 独自画像の使用
- **背景拡大率**: 画像の実サイズを基準に倍率を指定
- **OBSサイズ表示**: 拡大率から計算した幅と高さを読み取り専用で表示
- **背景表示/非表示**: トグルで切り替え
- **画像アップロード**: ファイル選択ダイアログで簡単アップロード

### スティック設定

- **位置調整**: X座標、Y座標をピクセル単位で調整
- **サイズ調整**: 幅と高さをパーセントで調整
- **表示/非表示**: トグルで切り替え

### ボタン設定

- **総数設定**: 0〜48の範囲で設定
- **個別配置**: 各ボタンをドラッグ&ドロップで配置
- **個別サイズ**: 各ボタンの幅と高さを設定
- **個別画像**: 各ボタンに異なる画像を設定
- **押下時画像**: ボタン押下時の画像を separately 設定

### ボタンマッピング

- **ボタン割り当て**: ゲームパッドのボタンを表示ボタンに割り当て
- **軸割り当て**: アナログスティックをボタンとして割り当て
- **スティック方向割り当て**: スティックの各方向を割り当て
- **視覚的設定**: プレビュー上のボタンをクリックして割り当て

## レイアウト管理

### レイアウト保存

- **名前付き保存**: 任意の名前でレイアウトを保存
- **JSON形式**: 設定をJSONファイルとして保存
- **自動デフォルト更新**: 保存時にデフォルトレイアウトも更新

### レイアウト読み込み

- **一覧表示**: 保存したレイアウトの一覧から選択
- **即座に反映**: 読み込むとプレビューに即座に反映
- **名前自動設定**: 読み込んだレイアウト名が自動設定

### デフォルトレイアウト

- **起動時読み込み**: アプリ起動時に自動読み込み
- **設定ボタン**: 「Set as Default」で現在の設定をデフォルトに
- **ビューア同期**: ビューアもデフォルトレイアウトを使用

## 表示設定

### スケール

- **表示倍率**: 0.1〜3.0倍で調整
- **スライダー**: スライダーで直感的に調整
- **リアルタイム反映**: 変更が即座にプレビューに反映

### 背景透明度

- **透明度調整**: 0.0〜1.0で調整
- **OBS向け**: 背景を透過してOBSに重ねられる
- **スライダー**: スライダーで直感的に調整

## 入力履歴機能

### 表示モード

- **垂直モード**: 上から下へ時系列で表示
- **水平モード（下）**: 左から右へ、下側に寄せて表示
- **水平モード（上）**: 左から右へ、上側に寄せて表示

### 同時押しモード

- **ボタン組み合わせ**: 1+2、1+3などの組み合わせを表示
- **マッピング設定**: 各ボタンを組み合わせにマッピング
- **視覚的フィードバック**: 押されているボタンをハイライト

### 履歴管理

- **表示件数**: 1〜50件まで設定可能
- **自動スクロール**: 新しい入力が追加されると自動で表示
- **方向入力**: スティックの入力も履歴に表示

## ゲームパッド機能

### 自動検出

- **接続検出**: ゲームパッド接続を自動検出
- **切断検出**: ゲームパッド切断を自動検出
- **ポーリング**: 定期的に接続状態を確認

### ボタン割り当て

- **クリック割り当て**: プレビュー上のボタンをクリック
- **ボタン押下**: ゲームパッドのボタンを押して割り当て
- **軸ホールド**: アナログスティックを1秒間ホールドで割り当て
- **キャンセル**: 割り当てをキャンセル可能

### スティック割り当て

- **方向クリック**: プレビュー上のスティック方向をクリック
- **ボタン押下**: ゲームパッドのボタンを押して割り当て
- **軸ホールド**: アナログスティックを1秒間ホールドで割り当て

## OBS連携

### ブラウザソース

- **専用URL**: `/view`エンドポイントでビューアにアクセス
- **透過背景**: 背景を透過してゲーム画面に重ねられる
- **リアルタイム更新**: WebSocketでリアルタイムに状態を更新

### 設定

- **URL**: `http://localhost:33770/view`
- **幅**: 500px
- **高さ**: 250px
- **FPS**: 60fps

## サーバー機能

### プロセス管理

- **PIDファイル**: `server.pid`にプロセスIDを保存
- **npm stop**: PIDファイルを読み込んでプロセスを終了
- **シグナル処理**: SIGTERM/SIGINTでグレースフルシャットダウン

### API

- **REST API**: レイアウトのCRUD操作
- **WebSocket**: リアルタイム状態配信
- **画像アップロード**: Base64エンコードで画像を受信

### ファイル管理

- **レイアウト保存**: JSON形式で保存
- **画像保存**: Base64からデコードして保存
- **ディレクトリ管理**: レイアウトごとにディレクトリを作成

## 開発者機能

### TypeScript

- **型安全**: 完全なTypeScript実装
- **型定義**: `types.ts`にすべての型を定義
- **コンパイルチェック**: `tsc --noEmit`で型チェック

### ビルド

- **esbuild**: 高速なビルド
- **個別ビルド**: サーバー、エディタ、ビューアを個別にビルド
- **ソースマップ**: デバッグ用のソースマップ生成

### モジュール構成

- **関心の分離**: 各機能が独立したモジュール
- **再利用性**: 共通機能はモジュール化
- **テスト容易性**: 各モジュールを個別にテスト可能

## 制限事項

### ブラウザ制限

- **Gamepad API**: Chrome、Edge、Firefoxでサポート
- **HTTPS不要**: localhostではHTTPで動作
- **WebSocket**: モダンブラウザでサポート

### パフォーマンス

- **ボタン数**: 最大48ボタン
- **履歴数**: 最大50件
- **画像サイズ**: 最大100MB（Base64）

### 対応ゲームパッド

- **標準ゲームパッド**: Xbox、PlayStationコントローラー
- **アーケードスティック**: 標準Gamepad API対応機種
- **レバー**: 8方向レバー対応
